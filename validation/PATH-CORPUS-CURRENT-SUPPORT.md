# Independent path corpus: preparation status

`validation/path-corpus-support-v1.json` is generated by
`python tests/path_corpus/generate_support.py --out NEW_JSON` on Linux. It binds
each project-owned synthetic host to exact source hashes and records the public
command, oracle, Python and platform identities. It contains no source text,
private data or claimed application benefit.

The current Linux CPython 3.12.3 run reports five path-input hosts. Opaque and
ordinary-package hosts return `insufficient_evidence`; the simple callback-poor
host returns `deterministic_rejection`; the arithmetic host remains
`insufficient_evidence` pending complete source-scope review; and Go source
returns `incomplete_analysis`. Every case reports target execution and mutation
false. These are truthful **current command outcomes**, not successful connected
integration. The focused corpus oracle has 23 passing Linux cases, including
independent baseline behavior, four adversarial host mutations, public path
outcomes, and oversized-source coverage.

The JSON `unrun` field lists connected review/spec preparation, target-native
verification, interrupted apply/resume, forged external receipts, dirty-tree
guards, conflicting edits, installed-host lifecycle, hosted Python matrix and
non-Python backends. Those gates remain open until #6, #7 and #8 are integrated.
The previous branch's 1,447-test result was for an older repository revision;
it is historical and is not evidence for this branch. Independent review is
required if both a host and its oracle change.
