# Branding and attribution

The default report attribution is a clearly disclosed **CompleteTech provider starter**. It is not a claim that CompleteTech is the company whose repository is being analyzed. Supply the actual customer's `branding.profile` or use `branding.unbranded: true` to remove provider branding from generated reports.

`branding/profile.json` is a text-only starter with the user-provided CompleteTech palette. It contains no invented logo. No font files, proprietary logos, or copied TypeSafe visual assets are included. Names, marks and external assets remain subject to their owners' rights; the MIT software license does not transfer those rights.

Keep optional downstream branding separate from analytical scoring and model behavior. Branding cannot alter risk, evidence, confidence, recommendation or adoption gates. This package is an independent integration-analysis skill and does not claim official TypeSafe sponsorship.
