# Synthetic source-bound discovery examples

The `opaque_host/opaque.py` file was authored by the assistant solely as a local
synthetic fixture. It is not a third-party or independently authored host corpus,
and no live provider, deployment, credentials or measured application benefit
are involved. Distribution follows the evaluator repository's MIT license.

The three JSON examples record an actual local discovery/admission of these
source bytes. Their root, module, schema and parser identities bind that
qualification location and version. AST serialization differs between Python
interpreters. After copying the fixture, changing interpreter or policy, or
installing a different engine, regenerate the report and nomination anchors.
The tests regenerate fresh anchors on each qualified interpreter. Do not edit
the root hash or treat an example digest as approval.

`nomination.example.json` is untrusted structured data. `admitted.example.json`
remains pending semantic and binding review. `report.example.json` is a capability
report, not an opportunity inventory, verification receipt or source mutation
plan. No target code is executed by the discovery command.
