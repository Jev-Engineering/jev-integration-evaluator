prune/compact choices. `scope-denied.example.json` intentionally grants nothing;
its zero hashes and example reference must never be treated as real authority.

`references/repository-session-command.md`. An actual reviewed inventory and
implementation specification are required; this directory does not fabricate a
source review, a permission-bearing callback or a replacement host function.

```sh
python scripts/run_repository_session_demo.py --out /fresh/private/session-demo
```

aggregate summary is synthetic software-wiring evidence, not provider connectivity,
measured benefit, independent-corpus qualification or production activation.
