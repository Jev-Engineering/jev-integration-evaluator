## Explicit cancellation seam

may additionally name `bindings.invocation_options`. That existing top-level
synchronous function must have exactly one identifier parameter and one return:

```javascript

```

The trusted AST transform permits only that object and property access. It
rejects extra options, async functions, calls, extra statements and generated

The runtime's existing AbortSignal handling then prevents selected or fallback

ordinary application's responsibility. This is an additive bounded shape,
not arbitrary options generation.
The qualified cancellation input is a real host-owned AbortSignal. Malformed or
non-AbortSignal values are outside this qualification; legacy assessment-failure
handling still permits only the independently validated baseline.
