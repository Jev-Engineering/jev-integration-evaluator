# Frozen implementation and study linkage

The `observed-*` commands freeze an exact applied implementation, reviewed placement set, study arms, runtime configuration, rubric, model, policy, environment, and optional monitor plan. The caller must retain the expected study, placement, implementation verification receipt, link, collection request, and collection digests outside the files being checked. `observed-link` accepts only a verified applied bundle whose implementation receipt is externally anchored. A changed owned source byte, environment, study, placement, model, policy, rubric, or monitor plan requires a fresh link.

The placement-set record is an independently reviewed identity envelope with exactly one selected candidate, the reviewed inventory hash, and a `selection_sha256` retained by its reviewer. This version links one implementation bundle and one placement only; composite placement sets are unsupported. The command validates its digest and candidate/inventory equality. It does not independently authenticate the external selection decision. The implementation verification receipt remains a synthetic host check; the link reports `verified_synthetic` wiring and `not_tested` provider connectivity.

`observed-collect-offline` requires a separately approved SHA-256 digest of the complete request, including its frozen link, fixture and independent label digests, pair/call/cost/failure bounds, and `egress: false`. Its adapter returns only reviewed, finite fixture outcomes. It does not run a target or provider. Each scheduled test pair remains in the denominator. Missing labels, fixtures, budget, or outcomes produce an incomplete collection. Timeouts and failures remain measured failed outcomes. The independent labels supply expected outcomes; fixture outputs cannot award themselves success. This is a synthetic orchestration qualification only. A real host collection adapter, live egress scope, independent observed labels, and observed benchmark are unsupported here and require separate authorization and implementation.

`observed-evaluate` rechecks the exact source link and collection seal. Complete synthetic pairs go through the existing frozen study evaluation, which recomputes statistics and deployment gate decisions from raw holdouts; calibration and test data retain the existing study split checks. A supplied gate bundle must match the study's frozen all-gate manifest. A legacy holdout summary is accepted only with its frozen threshold plan and raw holdout rows, and must exactly match recomputation. An incomplete collection cannot evaluate gate evidence. If the link includes a frozen monitor, supplied monitor rows go through the existing monitor evaluator with every scheduled assignment in its denominator. Only a `suspend` recommendation becomes an exposure action; a healthy window never resumes or expands exposure. All outputs retain `supported_benefit: false` and `activation_eligible: false` for this offline path.

The commands are `observed-link`, `observed-check`, `observed-collect-offline`, and `observed-evaluate`; use `--help` for required paths and separately anchored digests. `--monitor-plan` and `--monitor-digest` freeze monitor identity, while `--monitor-rows` and `--monitor-as-of` replay its raw outcomes. Never publish private target files, raw prompts, labels containing personal data, credentials, or receipt archives.
